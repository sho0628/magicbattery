# 静電気で充電マジック（Webアプリ）

「静電気でiPhoneを充電します」と言って、手で静電気を起こし、指を充電口に当てると
真っ黒の画面がロック画面に変わり、バッテリーが充電される——という**演出（表示のみ）**の
マジック用Webアプリです。実際には充電されません。

ビルド不要の素のHTML/CSS/JS。**PWA対応**でホーム画面に追加すると全画面・オフラインで動きます。

---

## 仕掛けの原理

1. 演技前にこっそり、**実際のiPhoneの残量**を入力しておく
2. アプリは「実際 − 2%（変更可）」の残量を表示して黒画面で待機
3. 黒画面を**長押し（約1.2秒）**するとセット完了（合図あり）
4. 設定した遅延（例: 5秒）後に、黒画面 → ロック画面に変わり充電アニメ開始
5. 残量が「実際の数字」まで上がっていく＝1〜2%充電されたように見える

---

## 使い方

### 初回（ホーム画面に追加して全画面に）
- iPhone Safariでこのアプリを開く → 共有 → **「ホーム画面に追加」**
- 追加したアイコンから開くと全画面（ステータスバーやURLバーが消える）

### 演技前の仕込み（左上を3回タップで設定が開く）
- **実際のバッテリー残量(%)**: いまのiPhoneの残量をそのまま入力
- **開始時に下げる量(%)**: 既定 2。この分だけ低く表示してから戻す
- **長押し→充電開始までの遅延(秒)**: 既定 5
- **充電アニメの時間(秒)**: 下げた分を戻すのにかける時間。既定 8
- **バイブ / 効果音 / 隅の光で合図**: お好みで
- **ロック画面の壁紙**: 「画像を選ぶ」で実機と同じ写真を設定（自動で縮小して保存）。「壁紙を消す」で初期の暗い背景に戻る
- **画面の暗さ**: 壁紙の上にかける黒さ。文字を読みやすく調整（0〜80）
- **時計・日付を表示**: 実機に合わせて非表示にもできる
- 「保存して黒画面へ」で待機状態に

### 本番
1. 黒画面の状態で、画面を**長押し**（約1.2秒）→ セット完了
2. 静電気を起こす演技をして、指を充電口（画面下の中央あたり）に当てる
3. 遅延後に充電が始まる
4. 終わったら **左上を3回タップ** → 「保存して黒画面へ」で次に備える

---

## 重要な注意（iOSの制約）

- **バッテリー残量の自動取得はできません**（iOS Safariは Battery API 非対応）。
  そのため毎回、実際の残量を手入力します。
- **バイブ（navigator.vibrate）はiOSでは動きません**（Android等のみ）。
  iPhoneでは代わりに「画面の隅が一瞬光る」合図を使ってください（既定でON）。
- 全画面・画面オフ防止は OS の仕様に依存します。ホーム画面に追加した状態での使用を推奨。

## 操作まとめ

| 操作 | 動作 |
| --- | --- |
| 黒画面を長押し（約1.2秒） | セット完了 → 遅延後に充電開始 |
| 左上を3回タップ | 設定パネルを開く |
| 「保存して黒画面へ」 | 設定を保存して待機状態に戻す |

## ファイル構成

- `index.html` … 画面
- `style.css` … スタイル（iOS風ロック画面）
- `app.js` … ロジック（状態管理・充電アニメ・合図）
- `manifest.json` / `icon.svg` … PWA
- `sw.js` … オフライン用 Service Worker
